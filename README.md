# TodoList App

Простое React-приложение для управления списком задач, собранное на Vite и развёрнутое на Vercel с настроенным CI/CD.

## Стек

- React 18
- Vite 5

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:5173`.

## Сборка проекта

```bash
npm run build
```

Собранные файлы попадут в директорию `dist`.

## Переменные окружения

Скопируйте `.env.example` в `.env` и укажите свои значения:

```bash
cp .env.example .env
```

- `VITE_API_KEY` — пример переменной окружения, используемой в приложении.

## Деплой на Vercel

1. Зарегистрироваться на [vercel.com](https://vercel.com) через GitHub.
2. Импортировать данный репозиторий в Vercel.
3. Настройки сборки:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Добавить переменную окружения `VITE_API_KEY` в Project Settings → Environment Variables.
5. При каждом пуше в `main` Vercel автоматически обновляет продакшн-версию, а при пуше в любую другую ветку создаёт превью-деплой с отдельной ссылкой.

## CI/CD

Для новой функциональности создаётся отдельная ветка (например, `feature-optimization`). После пуша Vercel автоматически собирает превью-версию по отдельной ссылке. После проверки ветка мержится в `main`, и продакшн-версия обновляется автоматически.
